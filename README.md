## 🌸 About The Portfolio

Welcome to my personal developer portfolio! Designed with a warm latte & beige color palette (`#fffaf5`, `#f4e9df`, `#4b3621`, `#b87572`), this website showcases my skills, featured web applications, engineering background, and my journey as a **Frontend Developer** and member of **Cloud Computing Cell (CCC)** at **Ajay Kumar Garg Engineering College (AKGEC)**.

🔗 **Live Website**: [https://muskan-portfolio-ipvv.vercel.app/](https://muskan-portfolio-ipvv.vercel.app/)

---

## ✨ Key Features

- **🎬 Interactive Welcome Screen**: Multilingual animated greeting sequence (*"Hello"*, *"नमस्ते"*, *"Welcome"*) with a real-time progress indicator and instant skip button.
- **🎨 Warm Aesthetic Beige Theme**: Handcrafted warm-latte aesthetic with soft shadows, glassmorphism badges, and elegant typography.
- **🖼️ Hanging Polaroid Profile Card**: Smooth pendulum swinging animation (`±2.2°` ease-in-out continuous physics loop) complete with simulated hanging cord and anchor pin.
- **🖱️ Sleek Custom Cursor**: Custom arrowhead desktop pointer with dynamic trailing motion dots (`• • • · ·`).
- **🔄 Core Competency Spotlight**: Dynamic text morphing and blur cycling through key competencies paired with an infinite scrolling marquee ribbon.
- **⚡ Society Affiliation Card**: Dedicated interactive badge linking to [Cloud Computing Cell (CCC)](https://www.cccakgec.com) at AKGEC.
- **📱 100% Responsive Design**: Carefully optimized for all viewports from mobile smartphones to ultrawide desktop monitors.
- **📬 Interactive Contact Section**: Functional contact form with client-side field validation and one-click direct social links.

## 💻 Getting Started

To run this portfolio on your local machine, follow the steps below:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18.x or later recommended) and `npm` installed.

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muskanji1007-lang/muskan-portfolio.git
   cd muskan-portfolio
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173/`.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```
